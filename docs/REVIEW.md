# 静的レビュー記録

## レビューの数え方

10種類の利用者・専門家ペルソナに対し、10個の確認テーマを適用し、合計100チェックポイントとしてレビューしました。

これは「Windows版Excelで100回動かした」という意味ではありません。作成環境にExcelがないため、実行試験は未実施です。100という数より、観点の重複漏れを減らすためのレビュー表であることを優先しています。

## 修正した主な指摘

- 64bitで大きさが変わる`ICMP_ECHO_REPLY`後半のポインターをUDTで直接受けず、共通配置の先頭14バイトだけを解析。
- API要求データにASCII固定文字列を使い、文字コード依存を縮小。
- `IcmpCreateFile`成功後は、通常・API失敗・VBA例外の全経路で`IcmpCloseHandle`へ到達。
- `requestCount`、`timeoutMilliseconds`、IPv4各オクテットをAPI呼び出し前に検証。
- 大量送信・長時間待機を避けるため、要求回数を1～10、タイムアウトを1～60000msに制限。
- IPv6一般化で必要になるスコープIDや名前解決を暗黙に省略せず、`::1`専用として明示。
- `ICMPV6_ECHO_REPLY`の`IPV6_ADDRESS_EX`が26バイトであることを再照合し、応答IPv6アドレスの開始位置を誤ったoffset 8から正しいoffset 6へ修正。親構造体のStatusはパディング後のoffset 28のまま。
- Traceシート作成失敗が通信処理を隠さないよう、イミディエイト出力を先行。
- TraceのA:Gを文字列書式にし、`Value2`で書いてExcelの自動型変換・数式評価を防止。
- UTF-8の日本語コメントがVBEで文字化けする場合のCP932変換・貼付け手順をREADMEへ追加。
- `DoEvents`が同期APIを非同期化するわけではない点をREADMEへ明記。

- Windows版Excel 64bitでのコンパイルと`127.0.0.1`実行
